## 1. Scope and Objective

This specification formalizes the exact mathematical definition, finite-sample algorithm, and execution contracts for **F-Mapper**. It defines the 1-D Fuzzy c-Means (FCM) filter cover construction, strict membership thresholding, threshold coverage-gap failure semantics, general simplicial nerve 2-skeletons versus abridged 1-skeleton graphs, deterministic centroid canonicalization, and integration with the locked M0 dual-homology framework.

Every implementation of F-Mapper within this project must conform strictly to this specification.

## 2. SOURCE-DEFINED Requirements (Bui et al., 2020)

### 2.1 Filter Space and Fuzzy Cover Formulation (Bui et al., §3 & Table 1)
1. **Filter Projection**:
   Given a finite point cloud dataset $X = \{x_0, x_1, \dots, x_{N_{\text{samples}}-1}\} \subset \mathbb{R}^d$ (or a metric space $(X, d_X)$), all points are projected to the real line via a continuous scalar lens function $f: X \to \mathbb{R}$, yielding 1-D filter values $y = (f(x_0), \dots, f(x_{N_{\text{samples}}-1})) \in \mathbb{R}^{N_{\text{samples}}}$.
2. **Cover Generation by Fuzzy c-Means (FCM)**:
   Unlike Classical/Conventional Mapper which covers the filter range with regular uniform intervals of fixed overlap $p$, F-Mapper covers the filter range using **Fuzzy c-Means clustering** applied directly to the 1-D scalar lens values $y$.
   - Parameters:
     - $N_{\text{intervals}} = c$: Number of fuzzy clusters / cover elements ($N_{\text{intervals}} \ge 1$).
     - $\alpha = m$: Weighting exponent / fuzzifier. Per Bui et al. (§2.4, p. 5), $\alpha = 2.0$ is the standard constant.
     - $\tau \in (0, 1]$: Overlapping membership threshold.
   - Objective function minimized by FCM:
     $$J_m(U, V) = \sum_{i=0}^{N_{\text{samples}}-1} \sum_{j=0}^{c-1} u_{ij}^\alpha (y_i - v_j)^2$$
     subject to $\sum_{j=0}^{c-1} u_{ij} = 1$ for all $i$, and $u_{ij} \in [0, 1]$.
   - Centroids and membership updates:
     $$v_j = \frac{\sum_{i=0}^{N_{\text{samples}}-1} u_{ij}^\alpha y_i}{\sum_{i=0}^{N_{\text{samples}}-1} u_{ij}^\alpha}$$
     $$u_{ij} = \frac{1}{\sum_{k=0}^{c-1} \left(\frac{|y_i - v_j|}{|y_i - v_k|}\right)^{\frac{2}{\alpha - 1}}}$$

### 2.2 Strict Thresholding Rule (Bui et al., Table 1 & §3)
- An observation $i$ belongs to fuzzy cover element $j$ if and only if its membership degree strictly exceeds the threshold $\tau$:
  $$i \in \text{CoverElement}_j \iff u_{ij} > \tau$$
- **Strict Inequality Contract**:
  - Equality $u_{ij} = \tau$ does **NOT** include sample $i$ in cover element $j$.
  - Soft FCM memberships are thresholded into an overlapping binary incidence relation without argmax or one-hot class hardening. An observation may belong to zero, one, or multiple fuzzy cover elements.
  - The resulting pullback subsets $X_j = \{x_i \in X \mid u_{ij} > \tau\}$ are generally irregular and may exhibit non-consecutive multiway overlaps.

### 2.3 General Form vs. Abridged Form (Bui et al., §3 & Fig. 7)
Bui et al. (§3, p. 6–7 and Fig. 7) explicitly distinguish two structural outputs for F-Mapper:
1. **General Form**:
   The complete membership-defined simplicial nerve generated by all genuine multiway intersections of the refined pullback clusters. Even with a single 1-D lens, higher-dimensional intersections can occur across multiple overlapping fuzzy cover elements.
2. **Abridged Form**:
   Restricts the complex to pairwise intersections only, producing a 1-skeleton graph (dimension $\le 1$). Bui et al. used the abridged form in their empirical evaluations to ensure structural comparison with classical 1-D Mapper graphs.

> **Project Simplex Materialization Contract**:  
> For this evaluation framework, the general F-Mapper nerve is mathematically defined by all genuine sample intersections. The project materializes its **membership-defined 2-skeleton** $(\Sigma_0, \Sigma_1, \Sigma_2)$, which is mathematically necessary and sufficient to compute exact $\beta_0^{\rm nerve}$ and $\beta_1^{\rm nerve}$.  
> The abridged form corresponds directly to the **1-skeleton graph** $(\Sigma_0, \Sigma_1)$.  
> Dual homology reporting is mandatory:
> $$\beta_1^{\rm graph} = E - V + C \quad \text{(Abridged 1-Skeleton Cycle Rank)}$$
> $$\beta_1^{\rm nerve} = \dim H_1(\mathcal{N}^{(2)}; \mathbb{F}_2) \quad \text{(General 2-Skeleton Nerve Homology)}$$

## 3. FROZEN PROJECT-CONTRACT CHOICES

### 3.1 1-D FCM Solver Specification and Canonical Centroid Ordering
1. **Solver Hyperparameters**:
   - `fcm_fuzzifier`: $\alpha = 2.0$ (fixed per Bui et al.).
   - `fcm_convergence_tolerance`: $\epsilon_{\text{conv}} = 10^{-7}$.
   - `fcm_max_iter`: $k_{\max} = 300$.
   - Centroid initialization is deterministic: initial 1-D centroids are the `c` evenly spaced values `numpy.linspace(min y, max y, c)` over the observed scalar lens range. The retained `fcm_seed` interface parameter does not alter centroid initialization and is not an experimental factor.
2. **Membership Matrix Validation**:
   Upon termination of FCM, validate the membership matrix $U \in \mathbb{R}^{N_{\text{samples}} \times c}$:
   - All entries finite (no `NaN`, `Inf`).
   - $0 \le u_{ij} \le 1$ for all $i, j$.
   - Row sums: $|\sum_{j=0}^{c-1} u_{ij} - 1.0| \le 10^{-5}$ for all $i$.
   - If FCM fails to converge within $k_{\max}$ iterations, set `status = "fcm_non_convergence"`, `scientific_evidence_eligible = False`.
3. **Canonical Centroid Ordering Contract**:
   To ensure deterministic permutation invariance:
   - After convergence, extract 1-D cluster centroids $v_j \in \mathbb{R}$ for $j = 0, \dots, c-1$.
   - Sort centroids in ascending numerical order: $v_{\pi(0)} \le v_{\pi(1)} \le \dots \le v_{\pi(c-1)}$.
   - For exact centroid ties ($v_a == v_b$), use the original column index as deterministic tie-break.
   - Permute the columns of $U$ by permutation $\pi$: $U_{\text{canon}}[:, j] = U[:, \pi(j)]$.
   - Centroids and cover elements are referenced strictly in this canonical sorted order.

### 3.2 Threshold Coverage-Gap Contract (Failure Semantic)
- If, after strict thresholding ($u_{ij} > \tau$), any observation $i$ satisfies:
  $$u_{ij} \le \tau \quad \forall j \in \{0, \dots, c-1\}$$
  then observation $i$ is uncovered by the thresholded cover.
- In this case:
  - `status = "coverage_gap"`
  - `scientific_evidence_eligible = False`
  - Record diagnostic metadata:
    - `uncovered_sample_indices`: list of integer sample IDs.
    - `threshold_coverage_fraction`: $\frac{N_{\text{samples}} - |\{i \text{ uncovered}\}|}{N_{\text{samples}}} < 1.0$.
  - Discard downstream scientific claims; do not silently drop uncovered observations.

### 3.3 Degenerate Constant-Lens Contract
- If the scalar lens is exactly constant ($f_{\max} == f_{\min}$) and $N_{\text{intervals}} > 1$:
  - `status = "fcm_degenerate_input"`
  - `scientific_evidence_eligible = False`
  - Do NOT collapse to Conventional Mapper's single interval; FCM cannot construct distinct clusters on degenerate identical points.
- If $N_{\text{intervals}} = 1$:
  - Trivial single fuzzy cover element $U[:, 0] = 1.0$. If $\tau < 1.0$, proceed normally.

### 3.4 Pullback Refinement, Clustering, and Node Identities
- For each canonically ordered cover element $j \in \{0, \dots, c-1\}$:
  - Extract pullback sample indices:
    $$X_j = \{i \in \{0, \dots, N_{\text{samples}}-1\} \mid U_{\text{canon}}[i, j] > \tau\}$$
  - If $X_j = \emptyset$, cover element $j$ produces 0 nodes.
  - If $X_j \neq \emptyset$:
    - Instantiate fresh clusterer clone (`sklearn.base.clone`).
    - Fit clusterer on coordinates $X[X_j]$ or precomputed principal submatrix $D[\text{np.ix\_}(X_j, X_j)]$.
    - Exclude clusterer noise label `-1`; no synthetic singleton override.
    - Validate returned label array shape and type.
    - Assign deterministic sequential integer node IDs $v \in \{0, \dots, |V|-1\}$ ordered by cover index $j$ then cluster label.
    - Distinct pullback clusters with identical sample supports ($S(v_a) = S(v_b)$) **must remain distinct nodes** (NO DUPLICATE MERGING).

### 3.5 Simplicial Nerve 2-Skeleton & Dual Homology (Locked M0 Reuse)
- Reuse locked M0 modules without alteration:
  - Build sample incidence sets $M_i = \{v \mid i \in S(v)\}$.
  - Generate 0-, 1-, and 2-simplices via `build_membership_nerve_2d` from `mapper_framework.nerve`.
  - Compute dual homology via `compute_dual_homology` from `mapper_framework.homology_gf2`.
  - Enforce chain condition $D_1 D_2 \equiv 0 \pmod 2$, $\beta_0^{\rm nerve} = C$, and bound $0 \le \beta_1^{\rm nerve} \le \beta_1^{\rm graph}$.
  - Strictly prohibit clique completion or graph-rank substitution.

## 4. Forbidden Substitutions

1. **NO Clique Completion**: $\Sigma_2$ is formed strictly by genuine 3-way sample intersections.
2. **NO Graph-Rank for Nerve Substitution**: Never report $\beta_1^{\rm graph}$ as $\beta_1^{\rm nerve}$.
3. **NO Argmax / One-Hot Hardening**: Cover sets must reflect soft thresholding ($u_{ij} > \tau$), never `argmax_j(u_{ij})`.
4. **NO Silent Coverage Gap Acceptance**: Never treat a coverage-gap construction as valid scientific evidence.
5. **NO Duplicate Node Merging**: Never merge distinct pullback clusters based on identical sample support sets.
6. **NO Singleton Overrides**: Clusterer noise label `-1` must never be converted into a node.

## 5. Failure Semantics & Status Matrix

| Execution Case | `status` | `scientific_evidence_eligible` | Graph Invariants | Nerve Invariants | Action |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Empty dataset ($N=0$) | `configuration_invalid` | `False` | `None` | `None` | Raise `ValueError` / return status |
| Exactly constant lens ($f_{\max} == f_{\min}, c > 1$) | `fcm_degenerate_input` | `False` | `None` | `None` | Return status; halt |
| FCM fails to converge | `fcm_non_convergence` | `False` | `None` | `None` | Return status; halt |
| Threshold coverage gap ($\exists i, \forall j: u_{ij} \le \tau$) | `coverage_gap` | `False` | Populated for diagnostics | Populated for diagnostics | Log uncovered samples; mark non-eligible |
| Clusterer exception in non-empty pullback | `clusterer_failure` | `False` | `None` | `None` | Halt entire invocation |
| All pullback points noise (`-1`) | `degenerate_output` | `True` | $V=0, E=0, C=0$ | $\beta_0=0, \beta_1=0$ | Valid empty complex |
| Full success | `success` | `True` | Valid ($V, E, C, \beta_1^{\rm graph}$) | Valid ($\beta_0^{\rm nerve}, \beta_1^{\rm nerve}$) | Full verified output |
