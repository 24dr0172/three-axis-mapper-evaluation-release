## 1. Scope and Objective

This specification establishes the exact, source-faithful mathematical definition and finite-sample computational algorithm for **Conventional Mapper**. It formalizes the input models, regular covering formulas, pullback refinements, clusterer isolation contracts, deterministic node indexing, duplicate-support node preservation, graph representations, and failure semantics.

Every implementation of Conventional Mapper within this project must conform strictly to this frozen specification. No experiment script, metric evaluator, or visualization utility may alter or bypass these rules.

---

## 2. SOURCE-DEFINED Requirements and Attribution

### 2.1 General Mathematical Formulation
Singh, Mémoli, and Carlsson (2007, §2.1 and §3.2) define the general Mapper construction:
1. **Continuous Formulation (Singh et al., §2.1)**:
   - Let $\mathbb{X}$ be a topological space and $Z$ a parameter space (here $Z = \mathbb{R}$).
   - Let $f: \mathbb{X} \to Z$ be a continuous function (the *filter* or *lens*).
   - Let $\mathcal{U} = \{U_\alpha\}_{\alpha \in A}$ be a finite open cover of $Z = \operatorname{im}(f)$.
   - The pullback cover of $\mathbb{X}$ is $f^*(\mathcal{U}) = \{f^{-1}(U_\alpha)\}_{\alpha \in A}$.
   - Decomposing each pullback open set $f^{-1}(U_\alpha)$ into its path-connected components yields a refined cover $\mathcal{V} = \{V_{\alpha, j}\}$, where $\bigcup_j V_{\alpha, j} = f^{-1}(U_\alpha)$ and each $V_{\alpha, j}$ is a path-connected component.
   - The *Mapper* of $(\mathbb{X}, f, \mathcal{U})$ is the simplicial nerve $\mathcal{N}(\mathcal{V})$.

2. **Finite-Sample Intersection Principle (Singh et al., §3.2)**:
   - Given a finite point cloud data sample $X = \{x_0, x_1, \dots, x_{N-1}\} \subset \mathbb{R}^d$ (or a finite metric space $(X, d_X)$) and scalar lens values $f(X) = (f(x_0), \dots, f(x_{N-1})) \in \mathbb{R}^N$.
   - A finite covering $\mathcal{U} = \{I_0, I_1, \dots, I_{n-1}\}$ of the parameter range is generated by overlapping 1D intervals.
   - For each interval $I_k \in \mathcal{U}$, the finite-sample pullback subset is:
     $$X_k = \{x_i \in X \mid f(x_i) \in I_k\} \subseteq X$$
   - A declared clustering algorithm $\mathcal{C}$ is applied to each non-empty subset $X_k$ using the metric $d_X$, producing a set of clusters $\{C_{k, 0}, C_{k, 1}, \dots, C_{k, m_k-1}\}$ which cluster $X_k$.
   - Each cluster $C_{k, j}$ defines a vertex (node) in the Mapper complex.
   - Each vertex carries the exact subset of sample indices $S(v) = \{i \in \{0, \dots, N-1\} \mid x_i \in C_{k, j}\}$.

### 2.2 Locked Source-Attribution Statement
> **Source Attribution Contract**:  
> Singh et al. (2007, §2.1 and §3.2) provide the general nerve-based Mapper construction and finite-sample intersection principle. For the scalar finite-sample Conventional Mapper used here, the primary reported Mapper object is the 1-skeleton graph:
> - vertices = retained pullback clusters;
> - edges = shared observed samples between node supports ($S(u) \cap S(v) \neq \emptyset$).
> 
> The project additionally reconstructs the membership-defined 2-skeleton from the retained node supports in order to compute $H_0$ and $H_1$ of the corresponding membership nerve. This project diagnostic follows the general nerve definition; it must not be interpreted as a claim that the original scalar finite-sample implementation explicitly materialises the complete 2-skeleton.

## 3. Mathematically Necessary Consequences

1. **Local Refinement**: Local clustering within each pullback set $X_k$ estimates the connected components of $f^{-1}(I_k)$. If $X_k = \emptyset$, no nodes are created for interval $I_k$.
2. **Intersection Source**: Edges and higher simplices exist **only** by virtue of shared observed data points. If two intervals $I_k, I_{k+1}$ overlap in filter space, but no sampled point in $X$ falls into the overlap region, or if points in the overlap fall into disjoint clusters, no edge is constructed.
3. **Nerve vs. 1-Skeleton Graph Separation**: A triple of vertices $\{u, v, w\}$ having pairwise non-empty intersections ($S(u) \cap S(v) \neq \emptyset$, $S(v) \cap S(w) \neq \emptyset$, $S(u) \cap S(w) \neq \emptyset$) forms a 1-skeleton cycle ($\beta_1^{\rm graph} \ge 1$), but forms a 2-simplex in the nerve **if and only if** the mutual triple intersection is non-empty ($S(u) \cap S(v) \cap S(w) \neq \emptyset$).
4. **Nerve of Retained Nodes vs. Full Cover**: When a clusterer marks certain points as noise (e.g. DBSCAN label `-1`), those points do not belong to any retained node. Consequently, the collection of node supports $\{S(v)\}_{v \in V}$ forms a cover of the *retained clustered subset* $\bigcup_{v \in V} S(v) \subseteq X$, not necessarily of the entire sample $X$. The complex is formally the **membership-defined nerve of the retained Mapper nodes**.

## 4. FROZEN PROJECT-CONTRACT CHOICES

### 4.1 Input Specification & Validation Contract

The algorithm supports two distinct input modes, declared via the parameter `input_mode`:

#### Mode 1: Coordinates Mode (`input_mode = "coordinates"`)
- `X`: Real-valued 2D array of shape $(N, d)$ where $N \ge 1$ and $d \ge 1$.
- `lens`: Real-valued 1D array of shape $(N,)$ representing scalar filter values $f(x_i) \in \mathbb{R}$.
- Validation:
  - Check $N = \text{len}(X) = \text{len}(\text{lens})$.
  - Verify all entries in $X$ and `lens` are finite (no `NaN`, `+Inf`, `-Inf`).
  - If $N = 0$, raise `ValueError("Input dataset X is empty (N=0).")`.

#### Mode 2: Precomputed Distance Mode (`input_mode = "precomputed_distance"`)
- `X`: Real-valued 2D square distance matrix $D$ of shape $(N, N)$ where $N \ge 1$.
- `lens`: Real-valued 1D array of shape $(N,)$.
- Validation:
  - Check $D$ is a square 2D matrix with shape $(N, N)$ and $\text{len}(\text{lens}) = N$.
  - All entries finite (no `NaN`, `Inf`).
  - Non-negativity: $D_{ij} \ge -10^{-12}$ for all $i, j$.
  - Zero diagonal: $|D_{ii}| \le 10^{-12}$ for all $i \in \{0, \dots, N-1\}$.
  - Symmetry: $\|D - D^T\|_\infty \le 10^{-12} \cdot \max(1.0, \|D\|_\infty)$.
- Pullback distance submatrix:
  - For pullback indices $\text{idx} = X_k \subseteq \{0, \dots, N-1\}$, the submatrix passed to the local clusterer is the **principal submatrix**:
    $$D_k = D[\text{np.ix\_}(\text{idx}, \text{idx})] \in \mathbb{R}^{|X_k| \times |X_k|}$$
  - Slicing row-only is strictly prohibited.
  - The declared clusterer must be configured for precomputed metrics (e.g. `metric="precomputed"`).

### 4.2 Regular Cover Construction Formula

Let $f_{\min} = \min_{i} f(x_i)$ and $f_{\max} = \max_{i} f(x_i)$.

#### 1. Exactly Constant Lens Branch ($f_{\max} == f_{\min}$)
- The constant-lens branch is entered **ONLY** when all represented lens values are exactly equal:
  $$f_{\max} == f_{\min}$$
- Do not collapse a merely near-constant lens (if $f_{\max} \neq f_{\min}$, even by the smallest representable float, proceed to the standard regular cover formula).
- For an exactly constant lens ($f_i = c$ for all $i$):
  - `constant_lens = True`
  - `effective_n_intervals = 1`
  - The mathematical interval is $I_0 = [c, c]$.
  - Computational inclusion uses the outward representable float safeguard:
    $$I_{0, \text{eval}} = [\text{nextafter}(c, -\infty), \text{nextafter}(c, +\infty)]$$
  - All points $X$ are assigned to pullback $X_0 = \{0, 1, \dots, N-1\}$.

#### 2. Standard Regular Cover Formula ($f_{\max} > f_{\min}$)
- Total filter span: $R = f_{\max} - f_{\min} > 0$.
- Parameters:
  - `n_intervals` ($n \in \mathbb{Z}^+$): Number of covering intervals ($n \ge 1$).
  - `overlap_frac` ($p \in [0, 1)$): Fractional overlap between adjacent intervals.
- The uniform interval width $w$ and stride $s$ are:
  $$s = w(1 - p)$$
  $$R = (n - 1)s + w = w [n - p(n - 1)]$$
  $$\implies w = \frac{f_{\max} - f_{\min}}{n - p(n - 1)}$$
  $$s = w(1 - p) = \frac{(f_{\max} - f_{\min})(1 - p)}{n - p(n - 1)}$$
- Mathematical interval endpoints for $k \in \{0, 1, \dots, n-1\}$:
  $$a_k = f_{\min} + k \cdot s$$
  $$b_k = a_k + w$$
- Notice: $a_0 = f_{\min}$ and $b_{n-1} = f_{\min} + (n-1)s + w = f_{\max}$.

#### 3. Closed-Interval Boundary Semantics and Multiplicity
- Every mathematical interval is closed: $I_k = [a_k, b_k] = \{y \in \mathbb{R} \mid a_k \le y \le b_k\}$.
- **Semantic Meaning of $p = 0$**:
  - When $p = 0$, $s = w$. Interval boundaries meet at exact endpoints: $b_k = a_{k+1}$.
  - $p = 0$ denotes **zero positive-length overlap**, not necessarily mutually exclusive finite-sample memberships.
  - If a sample $x_i$ has $f(x_i) = b_k = a_{k+1}$ exactly, it belongs to both $I_k$ and $I_{k+1}$ under the closed-interval convention.
- **Overlap Multiplicity Regimes**:
  - For $0 \le p < 0.5$: A point $f(x_i)$ belongs to at most 2 intervals simultaneously.
  - At $p = 0.5$: $s = 0.5 w$. $b_k = a_{k+2}$. An exact boundary point $f(x_i) = b_k = a_{k+2}$ belongs simultaneously to 3 intervals ($I_k, I_{k+1}, I_{k+2}$).
  - For $p > 0.5$: Triple and higher overlap occurs over non-zero-length intervals $[a_{k+2}, b_k]$ of positive measure $(2p - 1)w > 0$.

#### 4. Locked Floating-Point Endpoint Rule (`nextafter` Safeguard)
> **Floating-Point Representation Rule**:  
> The mathematical cover is EXACTLY $I_k = [a_k, b_k]$ where $a_k$ and $b_k$ are defined by the mathematical regular-cover formulas. Floating-point handling must NOT redefine interval width, stride, overlap fraction, mathematical endpoints, or mathematical cover geometry.
> 
> For computational membership testing only, use an outward one-representable-value safeguard:
> $$a_{k, \text{eval}} = \text{nextafter}(a_k, -\infty)$$
> $$b_{k, \text{eval}} = \text{nextafter}(b_k, +\infty)$$
> and test represented floating-point lens values using:
> $$a_{k, \text{eval}} \le f_i \le b_{k, \text{eval}}$$
> 
> Outward `nextafter` is solely a floating-point representation safeguard for evaluating membership in the closed mathematical interval $[a_k, b_k]$. It does not modify the mathematical interval endpoints, cover width, stride, overlap, or regular-cover formula. All stored/reported mathematical endpoints remain $a_k$ and $b_k$.
> 
> All other arbitrary tolerance additions (e.g. fixed $10^{-12}$ interval inflation) are strictly removed.

### 4.3 Finite-Sample Pullback & Clusterer Contract

For each interval $I_k = [a_k, b_k]$ ($k \in \{0, \dots, n-1\}$):
1. **Pullback Extraction**:
   $$X_k = \{i \in \{0, \dots, N-1\} \mid a_{k, \text{eval}} \le f(x_i) \le b_{k, \text{eval}}\}$$
2. **Empty Pullback**:
   If $X_k = \emptyset$, interval $k$ yields 0 nodes.
3. **Clusterer State Isolation**:
   - For every non-empty pullback $X_k$, a fresh independent estimator instance is created from the declared unfitted clusterer configuration (e.g., via `sklearn.base.clone`).
   - Fitted state from one pullback must **never** leak into another pullback.
4. **Clustering Execution**:
   - Extract sub-data: $X_{\text{sub}} = X[X_k]$ (coordinates) or $D_k = D[\text{np.ix\_}(X_k, X_k)]$ (precomputed distance).
   - Execute declared clusterer: `labels = clusterer.fit_predict(X_sub)`.
5. **Output Validation & Noise Policy**:
   - Returned `labels` must have exactly $|X_k|$ entries.
   - Non-negative integer labels ($j \ge 0$) form valid clusters $C_{k, j} = \{X_k[l] \mid \text{labels}[l] == j\}$.
   - Noise label `-1` (e.g. DBSCAN noise) is **excluded** from forming nodes.
   - **No Singleton Override**: If the clusterer assigns label `-1` to a single point or small cluster, Mapper code must **not** override the clusterer to synthesize a singleton node. If singleton preservation is needed, it must be encapsulated in a separately named custom clusterer adapter, never embedded as hidden logic in Conventional Mapper.
   - If returned `labels` contains invalid types, invalid shapes, or unsupported negative values other than `-1`, the execution is marked as `status = "clusterer_failure"`.
6. **Clusterer Failure Exception Policy**:
   - If `clusterer.fit_predict` raises an unexpected exception for any non-empty pullback $X_k$, the **entire** Mapper invocation is marked as `status = "clusterer_failure"`.
   - The algorithm must not silently drop the failed pullback to construct a partial Mapper graph.

---

### 4.4 Deterministic Node Identity and Duplicate Preservation

1. **Deterministic Sequential Construction**:
   - Iterate intervals in strict ascending order $k = 0, 1, \dots, n-1$.
   - Within each interval $k$, extract unique non-negative cluster labels in strict sorted ascending order $j \in \text{sorted}(\operatorname{unique}(\text{labels}) \setminus \{-1\})$.
   - Assign global sequential integer node IDs $v \in \{0, 1, \dots, |V|-1\}$ consecutively.
2. **Node Attributes**:
   Each node $v$ stores:
   - `node_id`: Integer $v \in \{0, \dots, |V|-1\}$
   - `interval_idx`: Integer $k \in \{0, \dots, n-1\}$
   - `cluster_label`: Integer $j \ge 0$
   - `members`: Frozen set of integer sample indices $S(v) \subseteq \{0, \dots, N-1\}$ with $|S(v)| > 0$
   - `size`: Integer $|S(v)|$
   - `mean_filter`: Float $\frac{1}{|S(v)|} \sum_{i \in S(v)} f(x_i)$
3. **Preservation of Distinct Node Identities (NO DUPLICATE MERGING)**:
   - Node identity is defined by its pullback-cluster origin $(k, j)$, NOT merely by its set of members $S(v)$.
   - If two distinct nodes $v_a = (k_a, j_a)$ and $v_b = (k_b, j_b)$ happen to have identical sample sets $S(v_a) = S(v_b)$, they **must remain distinct nodes** in $V$.
   - Merging distinct nodes based on identical sample supports is strictly prohibited. Because $S(v_a) \cap S(v_b) = S(v_a) \neq \emptyset$, an edge $(v_a, v_b)$ will exist between them in the 1-skeleton graph.

---

### 4.5 1-Skeleton Graph Construction & Invariants

1. **Edge Set Construction**:
   $$E = \{(u, v) \mid 0 \le u < v < |V|, S(u) \cap S(v) \neq \emptyset\}$$
   Each edge carries attribute `weight = len(S(u) & S(v))`.
2. **Graph Summary Invariants**:
   - $V = |V|$ (total number of retained nodes).
   - $E = |E|$ (total number of edges).
   - $C = \text{number of connected components of } G = (V, E)$. If $V=0$, $C=0$.
   - $\beta_1^{\rm graph} = E - V + C$ (cyclomatic number / 1-skeleton cycle rank).

The mathematical specification in this document and the released unit tests are authoritative. No KeplerMapper cross-check result is shipped with this release, and agreement with KeplerMapper is neither claimed nor required.

## 6. Forbidden Substitutions

1. **NO Clique Completion**: Never construct the simplicial nerve by taking the flag complex / clique completion of the 1-skeleton graph.
2. **NO Graph-Rank Homology Fallback**: Never report $\beta_1^{\rm graph}$ under the name $\beta_1^{\rm nerve}$, or substitute $\beta_1^{\rm graph}$ when simplicial nerve computation fails.
3. **NO Hardening / Point Deduplication**: If sample $x_i$ belongs to multiple clusters/pullbacks, it must remain in all corresponding node sets.
4. **NO Silent Singleton Creation**: Never convert clusterer noise (`-1`) into a singleton node.
5. **NO Duplicate Node Merging**: Never merge distinct nodes merely because their observed support sets happen to be equal.

## 7. Failure Semantics and Return Structures

The Conventional Mapper core must distinguish the exact stage at which any failure or invalidity occurs:

| Execution Stage / Case | `status` | Reason / Details | Node Invariants ($V$) | Graph Invariants ($E, C, \beta_1^{\rm graph}$) | Nerve Invariants ($\beta_0^{\rm nerve}, \beta_1^{\rm nerve}$) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Case 1: Pre-Graph Failure** (Invalid input $N=0$, invalid $n, p$, distance error, or clusterer exception) | `configuration_invalid` or `clusterer_failure` | Exception details recorded | `NA` (or $V$ if complete node count reached) | `NA` | `NA` |
| **Case 2: Post-Graph / Pre-Nerve Failure** (All points noise, or resource failure during triangle construction) | `degenerate_output` or `resource_failure` | `all_points_unassigned` or `RESOURCE_LIMIT_EXCEEDED` | Valid ($V=0$ or $|V|$) | Valid ($E, C, \beta_1^{\rm graph}$) | `NA` (or $0$ for degenerate) |
| **Case 3: Post-Nerve / Homology Failure** (2-skeleton complete, but homology reduction ceiling hit) | `resource_failure` | Homology solver timeout/memory | Valid ($V$) | Valid ($E, C, \beta_1^{\rm graph}$) | `NA` |
| **Case 4: Full Success** | `success` | `None` | Valid ($V$) | Valid ($E, C, \beta_1^{\rm graph}$) | Valid ($\beta_0^{\rm nerve}, \beta_1^{\rm nerve}$) |

NEVER present an incomplete graph statistic as a valid complete graph invariant.
