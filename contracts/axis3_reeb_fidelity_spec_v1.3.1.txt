## 1. Scope and Objective

This specification establishes the mathematical foundations, evaluation contracts, reference hierarchies, and execution invariants for **Axis III: Topological and Reeb Fidelity**.

Axis III evaluates:
> **“How faithfully does a finite Mapper-family representation recover the topological / Reeb structure associated with the SAME underlying space and SAME scalar function, where such comparison is mathematically valid?”**

Axis III strictly delineates:
1. **Intrinsic Domain Topology**: Underlying space Betti numbers ($eta_k(S)$).
2. **Reeb Quotient Topology**: Continuous quotient space $R_f(S) = S / \sim_f$ induced by continuous scalar lens $f: S 	o \mathbb{R}$.
3. **Finite Mapper Graph Representations**: 1-skeleton graph $G_M = (V, E)$, 2-skeleton membership nerve $\mathcal{N}^{(2)}(M)$, and their scalar filtration diagrams.

## 5. Mapper Graph Filtration Rules & Attribution

### 5.1 Node Filtration Rule (PROJECT-CONTRACT)
For each vertex $v \in V(G)$ with non-empty observation support $S(v) \subseteq X$:
$$\operatorname{filt}(v) = rac{1}{|S(v)|} \sum_{x \in S(v)} f(x)$$
- Approved as `PROJECT-CONTRACT` via `DECISION-AXIS3-01`.

### 5.2 Edge Filtration Rule (STANDARD SIMPLICIAL LOWER-STAR)
For each edge $e = \{u, v\} \in E(G)$:
$$\operatorname{filt}(e) = \max(\operatorname{filt}(u), \operatorname{filt}(v))$$

## 6. Extended-Persistence Type Contract & Interpretation Limits

Extended persistence decomposes the topological transitions of a graph/function pair $(G, \operatorname{filt})$ into 4 disjoint subdiagrams:
1. $	ext{Ord}_0$: Ordinary 0-dimensional persistence ($b \le d$).
2. $	ext{Rel}_1$: Relative 1-dimensional persistence ($b \ge d$).
3. $	ext{Ext}_0^+$: Extended 0-dimensional persistence ($b \le d$).
4. $	ext{Ext}_1^-$: Extended 1-dimensional persistence ($b \ge d$).

- **NO TYPE FLATTENING**: Matching across distinct subdiagram types is strictly prohibited.
- **DIAGONAL PROJECTION COST**: For any off-diagonal point $p = (b, d)$, $\operatorname{dist}(p, \Delta) = rac{|d - b|}{2}$.
- **Type-Restricted Bottleneck Distance**:
  $$d_B(\mathcal{D}_1, \mathcal{D}_2) = \max_{k \in \{	ext{Ord}_0, 	ext{Rel}_1, 	ext{Ext}_0^+, 	ext{Ext}_1^-\}} d_B(\mathcal{D}_1[k], \mathcal{D}_2[k])$$
- **Type-Restricted 1-Wasserstein Distance**:
  $$W_1(\mathcal{D}_1, \mathcal{D}_2) = \sum_{k \in \{	ext{Ord}_0, 	ext{Rel}_1, 	ext{Ext}_0^+, 	ext{Ext}_1^-\}} W_1(\mathcal{D}_1[k], \mathcal{D}_2[k])$$
